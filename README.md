# Informativo Diário

Site do Informativo Diário de **Flavia Santos Contadora** (Flavia Santos Contabilidade e Consultoria Ltda).

- O conteúdo das edições vem do Google Doc "📰 Informativo Diário", uma guia por edição.
- O site é uma página única (`index.html`); as edições ficam no bloco `EDICOES`, da mais recente para a mais antiga.
- Publicado pelo GitHub Pages a partir da branch `main`.
- **Não publicar** abas do Google Doc marcadas com o ícone ❌ ou com título iniciado por "ANTIGO". Se uma edição publicada for marcada assim, ela deve ser retirada do site.
- A página `#conheca` (Conheça o escritório) e o bloco Avise-me fazem parte do site e devem ser mantidos.
